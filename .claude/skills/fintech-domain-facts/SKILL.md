# 금융 도메인 사실 (확인일 2026-11-10)

미션 문서에 아래 사실을 쓸 때는 이 표의 값을 그대로 쓰고, 확인일을 문서에 남긴다.
세율과 제도는 매년 바뀔 수 있으므로, 이 표에 없는 값은 공식 기관 자료를 확인한 뒤 이 파일에 먼저 추가한다.
확인하지 못한 규칙은 "이 미션의 규칙으로 정한다"고 쓰고 실제 제도처럼 쓰지 않는다.

## 1. 이자소득 원천징수 (은행 예금 이자)

| 항목 | 값 | 출처 |
|---|---|---|
| 소득세 | 이자 × 14% | 국세청 원천징수 안내 |
| 지방소득세 | **원천징수 소득세 × 10%** (이자 기준 1.4%) | 국세청 안내 예시: 이자 10,000원 → 소득세 1,400원, 지방소득세 140원, 실지급 8,460원 |
| 합계 | 15.4% | |

- 계산 순서: 소득세를 먼저 구하고, 지방소득세는 **절사 후 소득세**의 10%로 구한다. 15.4%를 한 번에 곱하면 끝수 처리 결과가 달라진다.
  - 예: 이자 28,767원 → 소득세 4,027.38 → 4,020 / 지방소득세 402 → 400 / 합계 4,420 / 실수령 24,347
  - 15.4%를 한 번에 곱해 10원 미만 절사하면 4,430원이 되어 결과가 다르다.
- 10원 미만 절사: 국고금관리법 제47조(국고금의 끝수 계산)가 근거로 인용되지만 조문 원문은 확인하지 못했다. 미션에서는 **"이 미션의 규칙: 소득세, 지방소득세 각각 10원 미만 절사"**로 쓴다.

## 2. 증권거래세 (2026년 기준, 매도 시에만 부과)

| 시장 | 증권거래세 | 농어촌특별세 | 합계 |
|---|---|---|---|
| 코스피 | 0.05% | 0.15% | **0.20%** |
| 코스닥 | 0.20% | 없음 | **0.20%** |

출처: KB 2026년 달라지는 세법(https://kbthink.com/tax/expert/gw/251230.html, 2025-12-30). 매수에는 부과하지 않는다.
증권사 위탁수수료는 회사, 채널마다 다르므로 미션에서는 "이 미션의 규칙: 매수, 매도 각각 체결금액의 0.015%, 원 미만 절사"처럼 정해서 쓴다.

## 3. KRX 주식 호가가격단위 (2023-01-25 시행, 코스피, 코스닥 동일)

| 주가 구간 | 호가단위 |
|---|---|
| 2,000원 미만 | 1원 |
| 2,000원 이상 ~ 5,000원 미만 | 5원 |
| 5,000원 이상 ~ 20,000원 미만 | 10원 |
| 20,000원 이상 ~ 50,000원 미만 | 50원 |
| 50,000원 이상 ~ 200,000원 미만 | 100원 |
| 200,000원 이상 ~ 500,000원 미만 | 500원 |
| 500,000원 이상 | 1,000원 |

경계 테스트 예: 1,999원(1원 단위 유효), 2,000원(유효), 2,001원(무효, 5원 단위), 19,990원(유효), 20,000원(유효), 20,010원(무효).

## 4. 주식 매매 제도

| 항목 | 값 |
|---|---|
| 정규시장 | 09:00~15:30 (장 시작 동시호가 08:30~09:00, 장 마감 동시호가 15:20~15:30) |
| 가격제한폭 | 기준가격 대비 ±30% (2015-06-15 시행) |
| 상, 하한가 끝수 처리 | **미확인**. 업무규정 시행세칙 원문을 확인하지 못했다. 2차 자료(https://www.theteams.kr/teams/6627/post/70056, 2026-11-10 확인)는 "기준가격 × 0.3을 기준가격의 호가단위 미만 절사한 금액을 기준가격에 더하고 뺀다"고 설명한다. 미션에서는 "이 Phase의 규칙"으로 정해서 쓴다 |
| 결제일 | **T+2** (체결일 포함 3영업일째). 월요일 체결 → 수요일 결제. 금요일 체결 → 다음 주 화요일 결제(공휴일 없을 때) |
| 매매 체결 원칙 | 가격 우선 → 시간 우선 (동시호가 시간에는 단일가 매매) |

- 체결 직후 매도 대금은 "D+2 예수금"으로 잡히고 결제일에 출금 가능 예수금이 된다. 국내 증권사는 결제 전 매도 대금으로 재매수하는 것을 허용하고, 출금은 결제일 이후에만 허용한다. 미션에서는 둘을 구분하는 필드(`예수금`, `D+2 예수금`)를 둔다.
- 2025-03-04부터 대체거래소 넥스트레이드(NXT)가 08:00~20:00에 운영된다. 미션은 KRX 정규시장만 다룬다.

| 용어 | 뜻 | 쓰면 안 되는 곳 |
|---|---|---|
| 홀드(주문가능금액 차감) | 미체결 매수 주문 금액만큼 주문, 출금 가능 금액에서 묶어두는 것 | - |
| 가수금 | 회계에서 성격이 확정되지 않은 입금을 임시로 처리하는 계정 | 주문 홀드를 가리킬 때 쓰지 않는다 |

| 대사(reconciliation) | 두 기록(원장 합계 vs 계좌 잔액, 당행 vs 대외기관)을 비교해 불일치를 찾는 작업 | - |

## 6. 복식부기 (은행 관점)

은행 입장에서 고객 예금은 **부채**(고객에게 돌려줘야 할 돈), 보유 현금은 **자산**이다.
자산 증가, 부채 감소, 비용 발생은 **차변**, 자산 감소, 부채 증가, 수익 발생은 **대변**에 적는다.

| 거래 | 차변 | 대변 |
|---|---|---|
| 고객 A 현금 10,000원 입금 | 현금(자산) 10,000 | 고객예금 A(부채) 10,000 |
| A → B 3,000원 당행이체 | 고객예금 A 3,000 | 고객예금 B 3,000 |
| A에게 이자 100원 지급 (세금 무시) | 이자비용 100 | 고객예금 A 100 |
| A에게 이자 10,000원 지급, 원천징수 1,540원 | 이자비용 10,000 | 고객예금 A 8,460 / 예수소득세 1,400 / 예수지방소득세 140 |
| A → 타행 C 5,000원 이체 (대외기관 정산 전) | 고객예금 A 5,000 | 타행이체미정산(부채) 5,000 |

계정과목 이름(`예수소득세`, `타행이체미정산` 등)은 이 레포에서 정한 이름이다. 실제 은행 계정과목 체계는 은행마다 다르다.
모든 분개는 차변 합계 = 대변 합계다. 은행 내부 송금은 결제망을 거치지 않는다. 타행이체는 금융결제원(KFTC) 전자금융공동망을 거친다.
